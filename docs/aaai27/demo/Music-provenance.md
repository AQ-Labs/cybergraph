# Original soundtrack

Soft electronic underscore composed and synthesized locally for this CyberGraph demo.
96 BPM; warm sustained chords, plucked melody, soft bass and brushed percussion.
No third-party recording, sample, melody, or Graphify soundtrack was used.
The score and synthesizer remain in the local production workspace as
`compose_music_v3.py`; this documentation package is not a complete audio/video
production environment.
The film mix automatically ducks the underscore beneath speech.
